## Introduction

RoadFusion is a novel roadside 4D mmWare radar-camera fusion framework for reliable 3D object detection in all weather conditions. This project aims to bolster autonomous driving systems by extending their perception capabilities beyond visual limitations, ensuring reliable performance in adverse weather scenarios.

## Data Download

To effectively utilize RoadFusion, you will need to download the following datasets:

1. **DAIR-V2X-I Dataset**
   - Download the DAIR-V2X-I dataset from [here](https://thudair.baai.ac.cn/index).

2. **V2X-Radar Datasets**
   - **[V2X-Radar](https://github.com/yanglei18/V2X-Radar)** is specifically designed for radar-based vehicle-to-everything (V2X) applications.
   - Download **V2X-Radar-mini** and **V2X-Radar-V** datasets from [here](http://openmpd.com/column/V2X-Radar/).
3. **RoadRC Dataset**
   - Our roadside 4D radar-camera dataset will release soon.
